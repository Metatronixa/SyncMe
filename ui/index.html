      Cloud (rclone)

      Configure OneDrive / Google Drive from the console. Remotes are stored in SyncMe’s Config\rclone.conf.

      Store repository password

      SyncMe keeps the restic encryption password in Windows Credential Manager — never in a config file. Use the same password you chose when the repository was created.

      Retention & integrity

      Controls restic forget/prune lifecycle and repository checks for the active set.

      Update available

      A newer SyncMe package is available.

      Install downloads the package, verifies SHA-256, backs up Config.ps1, then applies the update without overwriting your backup sets. SyncMe will restart when finished.
