KEEP THESE SAFE (offline + password manager):
[ ] restic repository password — REQUIRED for any restore (Credential Manager: SyncMeRestic or SyncMeRestic-<setId>)
    Keep a vault copy outside the Backup PC. Lose this password = repository unrecoverable.
[ ] SMTP / share passwords if used (SyncMeSmtp, SyncMeShare / SyncMeShare-<setId>)
[ ] Windows account password for the SyncMe task (Task Scheduler "run whether logged on")
[ ] This checklist printed or stored offline
[ ] Bookmark https://www.syncme.co.za for FAQ / User Guide

VERIFY AFTER BACKUP / BEFORE YOU NEED A REAL DISASTER RESTORE:
[ ] Run dry run after setup Apply, then a real backup
[ ] Read Reports/Logs (exit 3 = some source files unread)
[ ] Operations Check (repo health)
[ ] Restore to an EMPTY test folder; spot-check critical paths vs the source

IF THE RESTIC REPO IS HEALTHY:
1. On the Backup PC, open SyncMe-Menu.bat -> Operations / Restore
   OR open PowerShell in the SyncMe folder (e.g. C:\SyncMe).
2. Set password:  $env:RESTIC_PASSWORD = 'your-password'
3. List snapshots: restic -r "D:\SyncMe\repos\user1" snapshots
4. Restore: restic -r "D:\SyncMe\repos\user1" restore latest --target "E:\SyncMe-Restore\temp"
5. Clear: Remove-Item Env:RESTIC_PASSWORD

GUI restore (recommended):
- SyncMe.bat or SyncMe-Menu.bat -> Operations
- Refresh snapshots -> select a snapshot
- Browse selected -> open folders -> Use this path (optional include) OR leave include blank for full snapshot
- Suggest target folder OUTSIDE the restic repo -> Restore selected / Restore latest
- Windows has no restic mount; browse + restore is the supported path
- UNC snapshots cannot be restored on Windows — use a newer drive-letter snapshot

IF REPO CHECK FAILS (CORRUPTED / CHECK_FAILED):
- Do not prune further until investigated
- Run: restic -r "..." check
- Review Logs\backup-*.log

IF BACKUPS STOPPED SILENTLY:
- Check Task Scheduler: SyncMe-Backup / SyncMe-Backup-<setId>
- Confirm the task user matches Credential Manager secrets
- Check SyncMe-Watchdog task / overdue email
- Confirm Logs\sets\<setId>\last-success-utc.txt
- Confirm free space on the restic destination; cloud sets need rclone auth
- LAN-only sets skip Tailscale; offsite needs Tailscale on source + Backup PC

OPEN-FILE ISSUES (exit code 3):
- On source desktops, run OfficeAgent Shadow Copies (elevated)
- Prefer SourceMode=ShadowCopy in HTML reports

NEVER:
- Commit passwords to Config.ps1 or git
- Blindly run "restic unlock" while another backup is running
- Restore into the live restic repository folder

CREDENTIAL / TASK NAMES:
- Credential targets: SyncMeRestic, SyncMeSmtp, SyncMeShare
- Tasks: SyncMe-Backup, SyncMe-Watchdog
