WHAT THIS IS
  SyncMe backs up source files/folders to this Backup PC using restic.
  Create a backup set per source PC / schedule / destination.
  Destinations: local disk, NAS (UNC), or cloud via rclone (OneDrive / Google Drive).
  LAN and/or Tailscale for sources. HTML console in the browser. No database, no PHP.
  Not bare-metal imaging, antivirus, or ransomware protection.

WHERE TO INSTALL
  Install SyncMe ONLY on the Backup PC (Windows 10/11 or Windows Server).
  Source desktops only need a shared folder (+ Tailscale if offsite).

USER GUIDE
  Open UserGuide.html for the full guide (exit codes, restore, limitations).
  Online: https://www.syncme.co.za (same content + FAQ).
  SyncMe.bat asks whether to open the guide before starting the console.

CUSTOMER PACKAGE (minimal)
  Hand customers ONLY: SyncMe-Setup.cmd + SyncMe-Payload.zip (+ START-HERE).
  Build with: .\Build-SyncMeSetup.ps1
  Setup unpacks into C:\SyncMe and launches the wizard. Existing Config.ps1 is kept.

UPDATE FROM THIS PROJECT (technicians)
  On the Backup PC, from THIS SyncMe folder:
    .\Deploy-SyncMe.ps1 -Target C:\SyncMe
  That keeps your existing Config.ps1 and copies tools\restic.exe when present.
  Then run SyncMe.bat.

WINDOWS SERVER (customer / unattended)
  1. Use a dedicated Windows account for SyncMe (e.g. DOMAIN\syncme-backup).
  2. Log on as that account, run setup + wizard under it.
  3. In Schedule, keep "Run whether logged on or not" checked and enter that
     account's Windows password (stored in Task Scheduler).
  4. Credential Manager secrets (restic / share / SMTP) must be for the SAME account.
  5. Console is http://127.0.0.1:17845 only — manage via RDP (not a LAN website).
  6. Prefer email notifications; toasts are off by default.
  7. One backup set per user/source is typical — stagger run times; each set needs
     its own restic repository path (dedicated subfolder, never a drive root).
  8. After reboot, confirm overnight jobs still run WITHOUT staying logged on.

BEFORE YOU BEGIN (once)
  1. Share the folder(s) on the source PC so this PC can open \\source\share.
  2. LAN only: ensure this Backup PC can reach the share by UNC.
     Offsite: install Tailscale on source + Backup PC.
  3. restic is installed by the wizard if missing.
  4. For OneDrive/Google Drive: install rclone and complete OAuth from the console.

RUN
  Double-click SyncMe.bat
  Optionally open the User Guide when prompted.
  Browser opens http://127.0.0.1:17845/
  Keep the SyncMe window open while you use the console.
  Close that window when finished with the UI.

SCHEDULED BACKUPS
  After setup, Windows Task Scheduler runs backups (default: whether logged on or not).
  You do NOT need to leave SyncMe or the browser open overnight.

FIRST TIME
  SyncMe opens the setup wizard until you finish Apply once.
  Wizard covers: set name, restic, LAN/Tailscale + folders, destination,
  passwords, email (optional), schedule → Task Scheduler.
  SAVE THE RESTIC PASSWORD in a password manager or other safe place when
  you create it. Without it you cannot restore. Credential Manager on this
  PC is not enough if the Backup PC dies — keep your own vault copy.
  After Apply: Run dry run, then a real backup. Read Reports/Logs. Use
  Operations Check. Restore to an empty test folder and spot-check
  critical files against the source.

MULTIPLE SETS / FOLDERS
  One backup set can include several UNC folders.
  Use "Add backup set" for another PC or user (separate schedule/destination).
  The SyncMe-Watchdog task checks ALL sets for overdue last-success stamps.

DAY TO DAY
  SyncMe.bat → Dashboard (or SyncMe-Menu.bat)
  Use Restore on Operations when you need files back (restic snapshots).
  Browse selected walks folders inside a snapshot; Use this path fills include for a partial restore.
  Periodically re-verify: Check, or test restore to an empty folder.

DO NOT
  Edit Config.ps1 unless a technician asks you to.
  Put passwords in any text file (except your password manager / vault).
  Lose or discard the restic password — the repository becomes unrecoverable.
  Restore into the live restic repository folder.
  Rely on SyncMe alone against ransomware — keep offline copies separately.
